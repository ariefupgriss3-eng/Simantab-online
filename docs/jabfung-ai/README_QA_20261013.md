## Risiko penting
- **CI mock bukan bukti AI Gateway yang nyata berjalan**, karena format `input_file` dan kredensial model belum diuji terhadap API sungguhan.
- Source frontend dan Edge Function dapat berbeda dari produksi: perubahan source GitHub tidak otomatis memperbarui Edge Supabase; butuh deploy tersendiri.
- RLS `submission_requirement_checks` dan kolom workflow status termasuk audit tahap terpisah. Paket ini hanya mengamankan dua tabel hasil AI Jabfung dan RPC kuota yang ditarget.
- Menjalankan ulang AI pada berkas historis mungkin mengonsumsi token/biaya dan memperbarui hasil; tidak termasuk izin pengguna saat ini.
- Deployment preview Vercel, jika dibuat otomatis oleh integrasi GitHub, tidak boleh digunakan dengan akun/pengajuan produksi untuk menulis data.

## Petunjuk QA gratis
Jalankan pada clone lokal:
```sh
node --check web/jabfung-jenjang-enhancement.js
node --test web/tests/jabfung-ai-offline.test.mjs
```
Pengujian hanya membuat request sintetis dengan `fetch` yang ditimpa oleh mock.
Jangan menjalankan build lengkap di repo lama tanpa pemeriksaan: skrip build masih mengambil HTML dasar dari alias produksi, meskipun helper `secure-build.mjs` memetakan beberapa modul secara lokal.
